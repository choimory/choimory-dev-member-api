# 나와의 대화 규칙

- 한국어로 대화하자
- 문서를 적어달라할땐 항상 ---로 구분선을 그어 구분하며 맨밑에 새로 추가하는 형식으로 적을것
- 기존 글들은 수정하지 말고 질문과 대화를 1:1 형식으로 밑에 계속 추가하는 형식으로 적을것
- 맨 위에 목차도 적고 추가할때마다 업데이트 할것
- H1 > H2 > H3 형식으로 주제를 구분하며 적을것
- 파일은 utf-8로 작성

## example

```markdown
(기존 글들)

---

# (사용자 질문1)

> (질문내용)

# (답변제목)

(답변내용)

# (답변제목)

(답변내용)

## (답변제목하위)

(답변내용)

### (답변제목 하위하위)

(답변내용)

---

# (사용자 질문2)

> (질문내용)

# (주제1)

(답변내용)

# (주제2)

(답변내용)

## (주제2-1)

(답변내용)

### (주제2-1-1)

(답변내용)

```
